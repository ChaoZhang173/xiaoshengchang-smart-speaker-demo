小声场：Mac 智能音箱 Demo
朋友体验版使用说明

这个 Demo 使用 Mac 的麦克风听你说话，把录音发送给 SiliconFlow 做语音识别和回答，最后由这台 Mac 的系统语音朗读回答。它还带有白名单网络电台、本地时间、天气查询和 SQLite 长期记忆。

重要隐私提醒

1. 不要把 SiliconFlow API Key 发给分享者、Codex、ChatGPT 或任何聊天工具。
2. Key 只应在 configure_api_key.command 弹出的 macOS 钥匙串输入框中填写；输入时屏幕不会显示字符。
3. 真实 API 模式会把录音、转录文字、最近最多 2 轮对话，以及回答当前问题所需的少量非敏感长期记忆发送给 SiliconFlow。录音不会由本 Demo 写入本地磁盘。
4. 天气查询会把城市名发送给 Open-Meteo；播放电台会直接连接 SomaFM。网络服务会看到正常连接所需的 IP 和请求信息。
5. 明确说“记住……”时，短文字会保存在这台 Mac 的 SQLite 数据库。常见住址、联系方式、健康和财务信息会标为“仅本机私密”，不提供给云端模型。你可以在页面查看、逐条删除或确认后全部清空。
6. 如果不配置 Key，仍可进入“本地演示”，检查页面、麦克风、朗读、本地时间、长期记忆和电台功能，但不会生成真实大模型回答，天气也不会联网。

第一次运行

1. 在 Finder 中把整个 ZIP 完整解压到“下载”或“文稿”目录。不要在 ZIP 预览窗口中运行文件。
2. 双击 configure_api_key.command。
3. 如果 macOS 阻止打开：确认文件确实来自可信的朋友，然后右键该文件，选择“打开”。如仍被阻止，先尝试打开一次，再进入“系统设置 → 隐私与安全性”，找到相关提示并选择“仍要打开”。不要关闭 Mac 的安全保护功能。
4. 按窗口提示粘贴你自己的 SiliconFlow API Key并回车。Key 会进入这台 Mac 的钥匙串，不会写入分享文件。
5. 双击 start.command。Terminal 窗口会保持运行，浏览器随后自动打开。
6. 建议使用最新版 Safari 或 Chrome。浏览器请求麦克风权限时选择“允许”。
7. 先在右下方输入一句文字测试；成功后，再点击中央麦克风按钮说话，再点一次发送。
8. 页面右上角应显示“真实 API · SiliconFlow”。如果显示“本地演示”，通常表示这台 Mac 没找到 SiliconFlow Key。
9. 使用结束后回到 Terminal，按 Control-C 停止服务，然后可以关闭窗口。

可以马上试的几句话

- “现在几点？”
- “上海现在天气怎么样？”
- “播放音乐”“暂停音乐”“继续播放”“停止音乐”
- “记住我喜欢爵士乐”“你还记得我什么吗？”“忘记爵士乐”

网络电台有时会被浏览器的自动播放规则拦住。遇到提示时，在页面“网络电台”区域手动点击一次“播放”即可。

系统要求

- 一台 Mac，Intel 或 Apple 芯片均可。
- Python 3.9 或更高版本。启动器会自动检查；如果缺少或版本过旧，会在 Terminal 中给出清楚提示。
- 最新版 Safari 或 Chrome。
- 能访问 SiliconFlow API 的网络。
- 真实问答需要使用者自己的 SiliconFlow 账户、API Key，以及相应模型的使用资格或额度。

常见问题

一、双击脚本后提示无法验证开发者
只在你确认压缩包来自可信分享者且没有被修改时，右键脚本选择“打开”；必要时在“系统设置 → 隐私与安全性”选择“仍要打开”。不要全局关闭 Gatekeeper。

二、提示没有 Python 3
可以请懂技术的朋友或 Codex 帮忙安装 Python 3.9 或更高版本。安装后重新双击 start.command。不要为了运行本 Demo 而执行来源不明的安装命令。

三、浏览器没有打开
查看 Terminal 中以 http://127.0.0.1: 开头的地址，把完整地址复制到最新版 Safari 或 Chrome。

四、麦克风无法使用
检查“系统设置 → 隐私与安全性 → 麦克风”，允许 Safari 或 Chrome；同时检查浏览器对当前 127.0.0.1 网站的麦克风权限。

五、没有声音
检查 Mac 音量和当前声音输出设备。SiliconFlow 模式使用这台 Mac 或浏览器的系统语音朗读；如果系统没有合适的中文语音，回答文字仍会保留在页面中。

六、配置了 Key 但仍是本地演示
先在 Terminal 中按 Control-C 停止旧服务，再重新运行 configure_api_key.command，随后重新双击 start.command。

七、出现 401、403、429、503 或超时
401/403 通常与 Key、实名认证或模型权限有关；429 通常表示调用频率或额度限制；503/超时可能是模型繁忙或网络暂时不稳定。等待一会儿重试；不要把 Key 或完整请求截图发送给别人。

八、清空“本次对话”后为什么还记得偏好
“本次对话”只清除内存中的短期上下文。长期记忆位于页面下方的独立区域，必须逐条点“忘记”，或点击“全部忘记”并再次确认。

需要 Codex 帮忙时

把整个解压后的 smart-speaker-demo 文件夹交给你自己的 Codex，并让它先阅读 CODEX_HELP.md。Codex 不需要、也不应该知道 API Key 的内容。
